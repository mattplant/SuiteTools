## [1.0.0-beta.2] — 2026-08-17

`1.0.0-alpha.2` (2025-07-05) and `1.0.0-beta.1` (2025-10-05) were root `package.json` bumps only. They were never tagged. `v0.1.0` (2024-01-20) was the last git tag. This is the first tagged prerelease since then.

### ⭐ Highlights

- Rebuilt as a React hash-router SPA (Vite, Flowbite-React) with a shared API
- Documentation and licensing overhaul (GPL-3.0-or-later for code, CC BY 4.0 for docs)
- Clone is pinned (Node 24, Yarn 4) and CI typechecks, lints, tests, and builds

### 🎯 Why

The last tag was a 2024 proof of concept. Since then the app became a React SPA, the repo became a real monorepo, and the documentation and licensing story was written down — but we never cut a release. Version numbers moved in `package.json`; nothing was tagged. An unpublished docs pass sat in this file as `1.0.0-beta.1`. This cut is the first tagged look at that work, and it makes the next cut routine: one suite version, this file, a git tag, and a GitLab Release.

### 🖼️ Scope

- **Product** — Rebuilt the 0.1.0 tools as a React SPA. Added job runs, deeper script/SOAP log and concurrency views, and in-app license/notices.
- **Documentation** — Governance standards, architecture guides, contributor guides, layered error-handling docs, and dual license (GPL-3.0-or-later for code, CC BY 4.0 for docs).
- **License compliance** — Added `THIRD_PARTY_NOTICES.md` and an in-app notices page.
- **CI and toolchain** — Node 24 and Yarn 4.18.0 pinned; GitLab CI typechecks, lints, tests, and builds on merge requests and `main`. SuiteCloud deploy stays out of CI. Backend TypeScript is full strict; ESLint and Prettier were replaced by Biome.
- **Version identity** — Root `package.json` remains `1.0.0-beta.2`. `1.0.0-alpha.2` and `1.0.0-beta.1` were never tagged. `shared` no longer carries a leftover `0.1.0` (it is a private workspace, like frontend and backend).

### 👩‍💻 Developer Impact

- **Install** — No custom-record migration. Redeploy with `yarn deploy:all` (or the workspace `build-and-deploy` paths).
- **Reuse** — Documentation and diagrams are CC BY 4.0 (with attribution); source is GPL-3.0-or-later.
- **Clone** — Node 24 and this repo’s Yarn 4 are required. Other majors fail at `yarn install`.
- **Validate** — `yarn typecheck && yarn lint && yarn test && yarn build:all` is the local equivalent of CI.
- **Release** — A release is an annotated git tag `v<version>` plus a GitLab Release whose body is this file’s entry. There is no `yarn release` script and no npm publish.
- **Changelog** — Written at release time from conventional commits. Day-to-day merge requests do not edit this file.
